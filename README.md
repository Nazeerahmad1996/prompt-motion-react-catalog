# Prompt Motion — React 18 Catalog & Motion Studio

This Vite + React 18 application renders the first 5 AI motion designs from [prompt-motion.com](https://prompt-motion.com/) using deterministic 60 FPS `seek(t)` spring physics and includes their exact verbatim prompts.

## Quick Start

```bash
npm install
npm run dev
```
